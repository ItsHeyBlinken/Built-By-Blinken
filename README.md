# BytesByBlinken Media

**Website:** https://builtbyblinken.com

BytesByBlinken Media is a web design studio that builds professional websites for small businesses, especially local contractors and service businesses. Each project starts with a written scope, and sites are built, hosted, and kept up to date for the client.

This repository contains the source for the studio's website.

## Services

- Custom web design and development
- Responsive, mobile-friendly layouts
- SEO-minded page structure
- Website hosting and maintenance, including SSL and small content updates

## What's in this repository

| Path | Description |
|------|-------------|
| `index.html` | Home page |
| `templates.html` | Gallery of example templates |
| `pricing.html`, `pricing.css` | Plans and pricing |
| `style.css`, `tailwind-built.css` | Site styles (custom CSS and a prebuilt Tailwind CSS file) |
| `Site Templates/` | 16 example templates for industries such as automotive repair, home services, landscaping, real estate, weddings, healthcare, law, finance, and education |
| `images/` | Site images and logos |
| `robots.txt`, `sitemap.xml` | Search engine configuration |

The example templates are sample layouts, not client work. Each one is a starting point that gets customized to a client's brand.

## Tech

A static site built with HTML, CSS, and a small amount of JavaScript, with no build step or server-side code. It includes structured data (schema.org) and a sitemap for search engines.
